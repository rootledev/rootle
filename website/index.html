what it does

browse

Three miller columns — orgs → repos → trees — with a live syntax-highlighted preview pane. No local clone.

find & grep␣ f␣ g

Full-screen, Zed-style results: match chips, folded regions, per-file counts. Scope to a repo or search globally.

open & yank↵␣ y

Any file opens read-only in your editor. Yank the browser URL of anything you're looking at.

clonev:clone

Mark repos, run the wizard. Org selections fan out; destinations land at <dest>/<org>/<repo>.

configure:settings

In-app settings write config.toml and hot-reload themes. The ? popup lists every keybinding.

providers

GitHub ships in-tree. Anything else wraps in as a stdio child process speaking NDJSON-RPC — four methods make a provider.

quick start

$ curl -fsSL https://tknawara.github.io/rootle/install.sh | sh  # linux x86_64
$ cargo install rootle    # or from crates.io (Rust 1.88+)
$ rootle                  # repo search on first run; browser after that
$ rootle owner/repo       # jump straight into a repo

Or grab the static musl binary from the releases page. Auth is zero-friction: gh auth login or ROOTLE_TOKEN if already set up — everything else works anonymously. Full walkthrough in getting started; every knob in settings.

providers

rootle talks to backends through a small protocol, not to GitHub directly. [provider] kind = "stdio" spawns your adapter as a child process — see how the pieces fit in providers, or the scaffolding skill for wrapping your own backend.
