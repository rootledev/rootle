# Internal skills

Repo-development skills for rootle maintainers — harness specifics,
gotchas, and conventions. Not part of the public integration surface
(that lives in the repo-root `skills/`).

| Skill | Purpose |
|---|---|
| [rootle-component](rootle-component/SKILL.md) | scaffold a new UI component (trait contract, keymap, theming, tests) |
| [rootle-pr](rootle-pr/SKILL.md) | author PRs: what/why/how template + evidence contract (frames, screenshots, recordings) |
| [rootle-demo-capture](rootle-demo-capture/SKILL.md) | demo GIF + doc screenshots, with the capture gotchas |
