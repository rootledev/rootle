# Public skills

Skills for people integrating ghx with their own systems — shipped
with the repo, useful without touching its internals.

| Skill | Purpose |
|---|---|
| [ghx-provider](ghx-provider/SKILL.md) | scaffold a stdio provider for any source-control backend, with a conformance test gate |

Internal skills (repo development: component scaffolding, TUI
debugging, demo capture) live in `.agents/skills/` — not part of the
public contract.
